# مصادر البيانات والرصد | Data Sources and Attribution

## مصادر التوقع | Forecast providers

### Open-Meteo

المصدر الرئيسي للتوقعات والبحث الجغرافي وبيانات النماذج العالمية وجودة الهواء.

Primary forecast, geocoding, global model, and air-quality data source.

- https://open-meteo.com/
- https://open-meteo.com/en/docs

### Visual Crossing

مصدر ثانوي مستقل للمقارنة. يُستدعى من دالة خادمية ولا يظهر مفتاحه في المتصفح.

Independent secondary comparison provider. It is called through a serverless function, so its key is never exposed to the browser.

- https://www.visualcrossing.com/weather-api/

### WeatherAPI

مصدر ثانوي إضافي للحالة الحالية والتوقع القصير، ومحمي بدالة خادمية.

Additional current-condition and short-range provider protected behind a serverless function.

- https://www.weatherapi.com/

## الخرائط والرصد | Maps and observations

### OpenFreeMap and OpenStreetMap

خريطة الأساس والبيانات الجغرافية المفتوحة.

Open base map and geographic data.

- https://openfreemap.org/
- https://www.openstreetmap.org/

### MapLibre

محرك عرض الخريطة المسطحة والكرة الأرضية.

Rendering engine for the flat map and globe.

- https://maplibre.org/

### RainViewer

إطارات رادار الهطول السابقة.

Historical precipitation radar frames.

- https://www.rainviewer.com/api.html

### NASA GIBS

صور الأقمار الصناعية وطبقات الهباء الجوي.

Satellite imagery and aerosol observation layers.

- https://www.earthdata.nasa.gov/eosdis/science-system-description/eosdis-components/gibs

### GDACS

الأعاصير المدارية النشطة ومعلومات الإنذار.

Active tropical cyclones and global alert information.

- https://www.gdacs.org/
